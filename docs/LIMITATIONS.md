# BurnBlind — Limitations

## Scientific

- Sensor disagreement does not prove a missed fire.
- Different sensor resolutions create legitimate disagreement.
- Smoke projection is an approximate directional estimate.
- The current corridor assumes steady wind and straight-line advection; it does not model plume rise, atmospheric dispersion, or population exposure.
- Population exposure is an estimate.
- Historical patterns can change.
- Model scores require validation before being interpreted as calibrated probabilities.

## Operational

- MVP covers a limited geography.
- Data availability can vary.
- External APIs can fail.
- Cloud/quality flags can reduce confidence.

## AI

- The Investigation Agent can make mistakes.
- Agent output is advisory.
- Tool evidence is the source of truth.
- The agent must not invent unavailable evidence.
- Human review remains necessary for high-impact decisions.

## Product

BurnBlind is a monitoring and investigation aid, not an emergency-response authority.
