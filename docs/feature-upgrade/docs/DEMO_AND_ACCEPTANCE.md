# Demo + Acceptance

## 3-minute demo

0:00–0:20 Landing/problem.

0:20–0:50 Monitoring + Blind Spot Map.

0:50–1:15 Select high-priority event.

1:15–1:45 Show exposure corridor.

1:45–2:20 Run Investigation Agent and show evidence/uncertainty/recommendation.

## Definition of done

- [ ] Blind Spot Map works with real/replay data
- [ ] Sensor comparison works
- [ ] Exposure calculation works
- [ ] Action Center ranks real events
- [ ] Investigation uses a real model provider
- [ ] Agent tools return real evidence
- [ ] Agent output is schema validated
- [ ] Missing evidence is handled honestly
- [ ] CloudWatch traces visible
- [ ] Replay is deterministic
- [ ] Human outcome persists
- [ ] Frontend has loading/error/empty states
- [ ] Frontend is responsive/accessibile
- [ ] Tests pass
- [ ] Public repo
- [ ] <=3 minute video
- [ ] AWS usage is visible in the video
