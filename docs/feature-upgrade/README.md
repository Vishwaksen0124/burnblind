# BurnBlind Feature Upgrade Pack

This pack extends the existing BurnBlind implementation. It is designed to be applied to the existing flow, not rebuilt as a separate product.

## New product flow

Observe → Find Blind Spots → Detect Candidate Events → Cross-Sensor Evidence → Estimate Potential Exposure → Prioritize Action → Investigate → Human Review → Replay/Validation.

## Core additions

P0:
- Monitoring Blind Spot Map
- Cross-Sensor Disagreement Explorer
- Potential Exposure / Impact Corridor
- Action Center
- Investigation Agent with evidence/uncertainty
- Evidence Quality

P1:
- Investigation Timeline
- Blind Spot Replay
- Human Outcome Feedback
- Incident Brief

P2:
- Community View
- HYSPLIT-based dispersion

The core principle is: deterministic systems establish facts and scores; the agent interprets evidence and recommends human review.
