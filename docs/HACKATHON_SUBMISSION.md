# BurnBlind — Hackathon Submission Checklist

## Event

Environmental Hacks — October 8–11, 2026.

Official event page:
https://www.wemakedevs.org/aws/env

Official rules:
https://www.wemakedevs.org/aws/rules

## Required artifacts

1. Public repository
2. YouTube demo video up to 3 minutes
3. Short write-up covering problem, build, and AWS usage

## Video must visibly demonstrate

- problem
- product
- working dashboard
- event
- Investigation Agent
- AWS usage
- environmental impact

## Repository must contain

- source code
- README
- setup instructions
- architecture
- data provenance
- tests
- attribution
- deployment instructions
- no secrets

## Build-window compliance

Planning, learning, research and practice may happen before the event. Project implementation must start when the hackathon opens.

Repository history should remain consistent with the official rules.
